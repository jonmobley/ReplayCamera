# Replay ("Camera Moments") audit — 2026-10-12 (auditor B)

Audited branch save-unsaved-work-2026-10-10 (190c1de) — this is the code that shipped as build 3 (v1.3.0).
**main does not contain it** (23 files / ~860 lines behind). This audit branch is based on that branch.

## Status
- Debug build (simulator): OK. Unit tests 8/8 pass. One Sendable warning (RollingBufferRecorder.swift:326, harmless).
- Launch on iPhone 17 Pro sim: opens, shows the first-run "How Replay works" sheet and camera prompt. Camera itself
  can't run in the simulator (expected).
- Info.plist: camera, microphone, photo-add and photo-library usage strings all present and clear. No background modes.
- No crash-prone patterns of note (two `urls(...)[0]` lookups for Documents/Caches are safe).
- Denied camera → "Camera access is required" overlay; denied mic → "Mic off — clips will be silent". Good.

## Findings
- High: shipped build-3 code lives only on branch save-unsaved-work-2026-10-10; main is stale. Merge it to main so future
  builds don't lose it.
- High (fixed): privacy manifest declared only UserDefaults, but the app also reads file dates (MomentStore.swift:168/191)
  and free disk space (StorageMonitor.swift:20). Apple flags missing reasons (ITMS-91053) on upload. Added FileTimestamp
  C617.1 + DiskSpace E174.1. Build 3 as uploaded lacks them — include in the next build.
- Medium (fixed): first-run tips sheet was too short (medium height), so tip descriptions were cut off with "…".
  Now 75% height (draggable to full) and the text wraps. Verified by screenshot.
- Low: camera permission prompt appears on top of the first-run tips sheet at first launch (both at once). Product choice — could ask after "Got it".
- Low: `xcodegen generate` changes the committed Replay.xcodeproj (project.yml and project have drifted slightly).

## Fixed
- PrivacyInfo.xcprivacy reasons (verified in built app bundle).
- First-run sheet clipping (verified in simulator screenshot).

## Not verified
- Recording, clip saving, Photos saves (need a real iPhone camera).
